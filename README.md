## Digital Image Processing

This project demonstrates a variety of image processing techniques, ranging from basic tasks to modern deep learning applications. Examples include:

* Rock-Paper-Scissors recognition
* Face recognition
* Fruit recognition
* Basic OCR
* License plate recognition

A demo video is available for download in this repository.

---

### How to Run the Project using Docker

To run the app locally with Docker:

```bash
docker run -p 8501:8501 phucnguyenhoank/xlas-ck:1.0
```

After the container starts, open your browser and go to:

👉 [http://localhost:8501](http://localhost:8501)
